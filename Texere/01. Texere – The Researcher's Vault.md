*Ghidul este disponibil și în limba română: [[02. Texere – Vault-ul cercetătorului|Texere: Vault-ul cercetătorului]].*

Research is usually scattered: sources in Zotero, PDFs in folders, notes on paper or in Word, drafts on several laptops. **Texere** brings everything into one place, in Obsidian: sources, PDFs, reading notes, ideas, drafts and the final paper. It works for any research field; the examples come from philosophy.

![[Without and with Obsidian.png]]

| Stage | Without Texere | With Texere |
| --- | --- | --- |
| Finding a source | Saved in Zotero, the browser or a downloads folder | Imported by DOI or ISBN; the note and the PDF appear in the vault |
| Reading | Underlined PDFs, notes on paper or in Word | Highlights land in the source's note, with the page and a link back |
| Connecting ideas | You remember who said what | Notes link to each other: every source on a concept, in one place |
| Finding a quote | Searching PDFs, notebooks and folders | Search a word or a tag (e.g. `#disagree`) and get the passage with its page |
| Citing | Every citation and the bibliography by hand | Write `[@citekey, p. 34]`; citations and bibliography are generated |
| Submitting | Paste into Word and redo the layout | Export straight to Word or PDF |
| **Places you work in** | **6** | **1: the vault** |

**Step 1. Set up the vault (once)**

1. Install **Obsidian** (free) from [obsidian.md/download](https://obsidian.md/download).
2. Copy the whole vault folder to your laptop. In Obsidian, choose **Open folder as vault** and select it.
3. Choose **Trust author and enable plugins**.
4. The setup starts by itself. You only choose the language (English or Romanian) and where exported files are saved.
5. Open the **03. Texere – Setup report** note and begin with **Start here**. If it has a **What you need to do** section (e.g. install Pandoc or LaTeX), do that, then run the setup again.

> [!warning] If you don't trust the author
> Obsidian opens the vault in **Restricted mode**: you can read the notes, but no plugin runs. That means no setup, no **Help** button, no importing sources, no highlighting in PDFs and no export. To turn them on later: **Settings → Community plugins → Turn on community plugins**.

> [!tip] Something stopped working?
> Run the setup again: **Ctrl/Cmd + P** → **Texere: Setup**. If that doesn't help, see [[#8. Troubleshooting]].

**Step 2. Work.** Go to the stage you need:

1. **Add a source** → [[#3. Managing references]]
2. **Read and highlight** → [[#4. Reading and literature notes]]
3. **Write and cite** → [[#5. Writing academic papers]]
4. **Build the bibliography and export** → [[#6. Bibliography and export]]

**Have a question?** Click the **Help** button (the life buoy in the left sidebar) or **Ctrl/Cmd + P** → **Texere: Help**, and type it in your own words.

## 1. Introduction

Obsidian is a note-taking app that works with folders on your own computer:

- **Plain text:** notes are Markdown files (.md) that open in other apps too.
- **Local:** your data stays on your devices.
- **Links:** notes point to each other, like Wikipedia pages. This is what makes ideas connect.
- **Plugins:** extensions that adapt the app to the way you work.

The interface is explained in [this video](https://www.youtube.com/watch?v=z4AbijUCoKU).

### 1.1 Terms used in this guide

| Term | What it means |
| --- | --- |
| **Alias** | Another name for a note (e.g. **Ethics** also has the alias Etică). |
| **Backlinks** | The panel showing every note that links to the open note. |
| **BibLib** | The plugin that imports sources by DOI, ISBN or arXiv and builds the bibliography. |
| **Bibliography** (`bibliography.json`) | The file in **biblib** that Pandoc reads the source data from when exporting. |
| **Citation** | A reference in the text, written `[@citekey]`. On export it becomes e.g. (Craig, 2002). |
| **Citekey** | A source's unique code: author, a word from the title, year (e.g. `craig_philosophy_2002`). |
| **Command palette** | The list of all commands: **Ctrl + P** (Windows) or **Cmd + P** (Mac). |
| **CSL** | The citation style file (APA, Chicago etc.); here `biblib/apa.csl`. |
| **DOI, ISBN, arXiv** | Identifiers for articles, books and preprints, used to find a source's data. |
| **Graph View** | A visual map of your notes and their links (left sidebar). |
| **LaTeX** (MacTeX, MiKTeX) | The program Pandoc uses to create PDFs. |
| **Link** | A reference to another note, written `[[Note name]]`. |
| **Literature note** | A source's note in **References**: its data, the PDF and your highlighted passages. |
| **Pandoc** | The program that turns notes into Word, PDF and other formats. |
| **PDF++** | The plugin for highlighting PDFs and copying passages with a link to the page. |
| **Plugin** | An extension that adds features to Obsidian. |
| **Properties** | The fields at the top of a note (e.g. **branch**, **attachment**, **title**). |
| **Restricted mode** | Obsidian's mode with all plugins off, until you trust the author. |
| **Tag** | A word with `#` in front (e.g. `#fact`), used to search and group passages. |
| **Template** | A model note in **Templates** that you copy as a starting point. |
| **Vault** | The folder with all your notes, files and settings (including the hidden `.obsidian`). |
| **Zotero Connector** | The browser extension that sends a page's data straight to Obsidian. |

| Folder | What it holds | Can you change it? |

The **Branch**, **Subdomains**, **Theories**, **Concepts**, **Movements** and **Historical Periods** folders hold one short note for each item in [[Philosophy]]. Note names are in English, and each has a Romanian alias: type `[[Etică` and Obsidian suggests **Ethics**.

<font color="#d83931">Important:</font> Don't rename, move or delete **Media**, **biblib**, **References**, **Scripts**, **Templates** or **citekeylist**. In **References**, don't change the **id** and **citation-key** properties. Everything else can be edited or deleted.

> [!warning] Deleted **Scripts** or **Templates** by mistake?
> Copy the folder back from the original vault, restart Obsidian and run the setup again.

**The Philosophy note**

[[Philosophy]] maps the field: branches, subdomains, periods, movements, theories, concepts and authors.

- Use its values when you fill in a note's properties, so notes link to each other. Example: [[@vica_constantin_avatarobots_2026]] has [[Ethics]] as its **branch**; open [[Ethics]] and **Backlinks** shows every source in that branch.
- **Graph View** shows the links between notes.
- You can edit or restructure [[Philosophy]] for another field. Need a map for another field? Write to [hi@georgemihai.com](mailto:hi@georgemihai.com).

## 3. Managing references

Each source has a note in **References**, named after its citekey (e.g. `@craig_philosophy_2002`); its PDF is in **Documents**.

> [!example] The example sources
> The 5 sources in **References** (Blackburn, Constantinescu, Craig, Dummett, Vică) show what a literature note looks like. You can delete them after setup, with their PDFs; then also replace the example citations in [[New article]].

### 3.1 From Obsidian (the simplest)

1. **Ctrl/Cmd + P** → **BibLib: Create literature note**.
2. Enter the DOI, ISBN or arXiv ID and click **Lookup**. The data fills in automatically.
	![[Screenshot 2026-10-15 at 12.45.01.png]]
3. (optional) Attach the PDF now or later (see [[#3.3 Attaching a PDF]]).
	![[Screenshot 2026-10-15 at 12.48.16.png]]

No identifier (e.g. an old edition)? Fill in the data by hand in the same window.

### 3.2 From the browser, with Zotero Connector

1. Install [Zotero Connector](https://www.zotero.org/download/) for your browser.
2. Open the page of [an article](https://policyreview.info/articles/analysis/avatarobots-democracy-metaverse).
3. Click **Zotero Connector**, with **Obsidian** open and the Zotero app closed.

> [!warning]- Some data is missing?
> 1. In Obsidian, turn off **Settings → BibLib → Zotero Integration → Enable Zotero Connector**.
> 2. In the browser: **Zotero Connector → Options / Preferences → Advanced → Translators** → **Reset Translators**.
> 3. Reload the article's page, turn **Enable Zotero Connector** back on and try again.

### 3.3 Attaching a PDF

1. Drag the PDF into **Documents**.
2. Open the source's note (e.g. [[@craig_philosophy_2002]]).
3. In the **attachment** property, type `[[`, search for the file and select it.

## 4. Reading and literature notes

1. Open the source's note (e.g. [[@craig_philosophy_2002]]) and click the PDF's title in **attachment**.
	![[Screenshot 2026-10-16 at 09.18.45.png]]
2. Select a passage and pick a color from the **PDF++** palette.
3. Paste it into the note (**Ctrl/Cmd + V**). It starts with the color's tag and ends with a link (`@citekey, p.4`) to the page in the PDF.

| Color | Tag | What you mark |
| --- | --- | --- |
| yellow | `#fact` | the author's claims and theses |
| red | `#disagree` | ideas you disagree with |
| green | `#agree` | ideas you agree with |
| blue | `#connection` | links to other texts, authors or ideas |
| purple | `#question` | questions the text raises |
| orange | `#definition` | definitions |
| grey | `#word` | terms to remember |

![[Screenshot 2026-10-16 at 15.37.26.png]]

> [!example] How it works, from a real note
> In [[@craig_philosophy_2002]], a highlighted passage with the reader's comment underneath:
> ```
> #fact In fact philosophy is extremely hard to avoid, even with a conscious effort. @craig_philosophy_2002, p.12
> Even sceptics who said that philosophy is useless have a certain set of values…
> ```
> 1. **Highlight** in the PDF (yellow = `#fact`) and paste into the note.
> 2. **Comment** in your own words, under the passage.
> 3. **Write:** the first paragraph of [[04. Texere – Export test]] cites it as `[@craig_philosophy_2002, p. 12]`.
> 4. **Export:** the result is [[04. Texere – Export test.pdf]].

> [!tip] Tip
> - Search a tag (e.g. `tag:#disagree`) to gather the same kind of idea from all your readings.
> - After reading, fill in the note's **Thesis**, **Arguments**, **Counterarguments** and **Conclusions**.

## 5. Writing academic papers

### 5.1 Start from a template (optional)

Duplicate [[New article]], rename the copy and fill in **title**. Leave the **Bibliography** heading at the end empty: the bibliography appears under it on export.

### 5.2 Citing sources

Write `@` and the citekey in square brackets, e.g. [@vica_constantin_avatarobots_2026]. The citekeys are in [[citekeylist]] and in the note names in **References**.

| You write | Appears (APA) |
| --- | --- |
| `[@craig_philosophy_2002]` | (Craig, 2002) |
| `[@craig_philosophy_2002, p. 34]` | (Craig, 2002, p. 34) |
| `[@craig_philosophy_2002, pp. 34-36]` | (Craig, 2002, pp. 34–36) |
| `[@craig_philosophy_2002; @dummett_origins_1996]` | (Craig, 2002; Dummett, 1996) |
| `@craig_philosophy_2002 [p. 34]` | Craig (2002, p. 34) |
| `[see @craig_philosophy_2002, ch. 2]` | (see Craig, 2002, ch. 2) |

Always give the page when you quote or paraphrase.

## 8. Troubleshooting

First run the setup again: **Ctrl/Cmd + P** → **Texere: Setup**. Command missing? **Ctrl/Cmd + P** → **Templater: Create new note from template** → **New laptop setup**. Still not working? Follow the steps below.

### 8.1 Manual setup

The automatic setup does steps 3 and 5 for you. By hand:

1. **Copy the whole vault**, including the hidden `.obsidian` folder. On a Mac, **Cmd + Shift + .** shows hidden folders in Finder.
2. **Turn on the plugins:** **Settings → Community plugins → Turn on community plugins** (this also leaves Restricted mode).
3. **Check the bibliography tag:** **Settings → BibLib → Literature note tag** must be `literature_note, #literature_note`. Run **BibLib: Build bibliography**: the number of entries must match the notes in **References**.
4. **Install the export programs:** [Pandoc](https://pandoc.org/installing.html) and, for PDF, [MacTeX](https://tug.org/mactex/) (Mac) or [MiKTeX](https://miktex.org/) (Windows).
5. **Fill in Settings → Pandoc Plugin:**
	- **Output folder**: where exported files go (empty = next to the note).
	- **Extra Pandoc arguments**: one argument per line, starting with `--`: `--citeproc`, `--bibliography=` and `--csl=` with your vault's location (see below), and `--pdf-engine=xelatex`.
6. **Check the font:** the font in `mainfont` must be installed on your laptop (e.g. Times New Roman).

> [!tip] How to find the vault's location
> Right-click the **biblib** folder → **Reveal in Finder** (Mac) or **Show in system explorer** (Windows), then copy its path: on Mac, hold **Option**, right-click → **Copy "biblib" as Pathname**; on Windows, right-click → **Copy as path** and delete the quotation marks. Result:
> ```
> --bibliography=/Users/your-name/Documents/Texere/biblib/bibliography.json
> --csl=/Users/your-name/Documents/Texere/biblib/apa.csl
> ```
> The path must not contain spaces; if it does, rename the folder or let the automatic setup handle it.

### 8.2 If an error appears

The steps are those in [[#8.1 Manual setup]].

| What you see | Why | What to do |
| --- | --- | --- |
| "Restricted mode" or no plugins work | you didn't trust the author | step 2 |
| `citation ... not found` | the bibliography wasn't built or its path is wrong | steps 3 and 5 |
| `Undefined control sequence \citeproc` | comes with the error above | goes away once citations are found |
| Pandoc can't be found | Pandoc isn't installed or is elsewhere | step 4; then set **Pandoc path** (Mac: `which pandoc` in Terminal; Windows: `Get-Command pandoc` in PowerShell) |
| `xelatex not found` | LaTeX isn't installed | steps 4 and 5 |
| `The font "..." cannot be found` | the font in `mainfont` isn't installed | step 6 |
| the exported file doesn't appear | **Output folder** doesn't exist on your laptop | step 5 |
| the Pandoc commands aren't in the list | no note is active (e.g. a PDF is selected) | click in a note, then try again |
| MiKTeX asks to install packages | normal on the first PDF export | accept |
| BibLib builds fewer entries than there are notes | the notes' tag doesn't match the setting | step 3 |
| the BibLib, Pandoc or PDF++ commands are missing | plugins off or `.obsidian` missing | steps 1 and 2 |
| the setup doesn't start after **Trust author** | the **Texere** plugin is off | **Settings → Community plugins** → turn on **Texere** |
| the **Help** button or the **New laptop setup** script is missing | **Scripts** or **Templates** was deleted or renamed | copy it back from the original vault and restart Obsidian |
| Zotero Connector doesn't send the source | the Zotero app is open | close Zotero |
| Obsidian is slow at first | Smart Connections is indexing your notes | wait a few minutes |

## 9. Frequently asked questions

1. **Can I change the structure?**
	Yes, it's only a proposal. Changing settings or scripts needs technical knowledge or an AI assistant.
2. **What must I keep if I organize things differently?**
	The steps in [[#3. Managing references]], [[#5.2 Citing sources]] and [[#6. Bibliography and export]], the folders marked "No" in [[#2. Vault structure]], and the **BibLib**, **Pandoc Plugin** and **PDF++** settings.
3. **Something stopped working. What do I do?**
	See [[#8. Troubleshooting]].
4. **Can I use another citation style (e.g. Chicago)?**
	Yes. Download the .csl file from the [Zotero Style Repository](https://www.zotero.org/styles), save it in **biblib** and add a line `--csl=` with its full path in **Settings → Pandoc Plugin → Extra Pandoc arguments**. Running the setup again switches back to APA.
5. **I deleted some text by mistake. Can I get it back?**
	Yes: **Settings → File recovery** keeps earlier versions of your notes.
6. **Which version do I have, and how do I update?**
	See [[#11. Version history]]. To update: back up your vault ([[#7. Backups]]); from the new version copy over the guide, the **Scripts** and **Templates** folders and `.obsidian/plugins/texere`; don't replace **References**, **Documents** or your notes; restart Obsidian.
